《一级交通指挥》 LEVEL 1 TRAFFIC CONTROL

早高峰，赫伯恩高地一号十字的信号灯集体罢工。四条车流堵在路口，喇叭声此起彼伏——今天，只有你一名交通指挥在岗。

你是这个路口唯一的声音。手抬向哪边，哪股车流就动起来；但每次换向，都要等整个路口彻底清空。出租车、公交、急救车……每一辆都在等你的手势。哪条队伍排满四辆还不管，你就会少一颗心；急救车的警笛，也会越等越急。

从见习指挥，到三级、二级、一级，再到金牌指挥——看看你能让这座城市流动多久。

玩法

↑ ↓ ← → / WASD：放行同向车流
切换方向要等路口清空
任一方向排满 4 辆、迟迟不放行，扣 1 颗心
急救车优先放行，等太久会扣心
P 暂停 · M 静音 · Enter 开始/继续
